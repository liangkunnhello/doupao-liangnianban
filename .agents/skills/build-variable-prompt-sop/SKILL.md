# 变量提示词 SOP 反推

## 任务边界

严格区分三层：

1. 当前任务输出一份“变量提示词生成 SOP”。
2. 下游文本模型执行该 SOP，生成用户指定数量、结构不同的变量提示词模板。
3. 生图系统从每个模板的变量池中选择选项，展开为不含变量的具体提示词。

只执行第一层。不要直接输出普通生图提示词或变量提示词模板。

## 处理参考图

1. 检查全部参考图。多图在比例、素材类型或视觉机制上明显冲突时，先请用户确认，不要强行混合。
2. 优先采用用户明确指定的画面比例；用户未指定时，根据参考图像素比例确定，不得擅自改为 1:1、9:16 或 16:9。
3. 在内部提取以下视觉证据，不输出分析过程：
   - 素材类型与核心语义符号
   - 主体数量、位置、占比和完整性
   - 主体与外壳、圆环、底座、轨道或环境的关系
   - 整体轮廓、拓扑、层数、前后遮挡和透视
   - 材质、配色体系、光照、背景和留白
   - 稳定视觉骨架与可安全变化的维度
4. 将广告文案、数字、价格、条款、免责声明、Logo、水印、二维码和控件视为排除内容，不得提炼为视觉策略或变量。
5. 不虚构品牌、产品名称、功效、规格或参考图无法支持的业务事实。

## 编译独立 SOP

把观察结果转写成一份无需再次查看参考图即可执行的 SOP。SOP 中不得出现“按照参考图”“保持原图效果”“与图片一致”“参考上图”或其他依赖原图的表达。

SOP 必须包含以下九个部分：

1. `Role（角色）`：定义下游模型为该类纯视觉图标的视觉策略师和变量提示词编排专家。
2. `Goal（目标）`：要求严格生成用户指定数量的变量提示词模板，不是具体提示词。
3. `Aspect Ratio & Composition（比例与构图）`：写明比例、主体位置、占比、留白、裁切、视角和构图重心。
4. `Visual Invariants（固定视觉骨架）`：锁定所有结果必须继承的语义、结构和质量常量。
5. `Structural Fission Matrix（结构裂变矩阵）`：给出多个结构机制，支持下游模型生成真正不同的模板。
6. `Variable Prompt Rules（变量提示词规则）`：规定正文、变量语法和选项池。
7. `Quality Constraints（质量约束）`：要求主体完整、边缘清晰、层级明确，无错误结构和竞争主体。
8. `Exclusion Rules（固定排除项）`：写入本技能规定的完整排除句。
9. `Output Rules（输出规则）`：规定数量、完整性、独立性，以及只输出变量提示词结果。

不要把偶然细节全部锁死。固定项用于保留参考图的核心视觉机制；变量项用于扩大可生产空间。

## 强制结构裂变

要求下游模型先选择不同的结构骨架，再填写变量。任意两套变量提示词至少在两个结构维度上明显不同：

- 主体与外围元素的拓扑关系
- 包围、嵌套、支撑、悬浮、穿插、连接或放射方式
- 主体层数和前后层级
- 外轮廓或承载结构
- 空间组织和遮挡关系
- 视角与透视
- 前景、中景、背景之间的关系

只改变核心物、颜色、材质、光影或背景，不算结构不同。禁止复用同一句式后仅替换变量名。

结构裂变必须围绕参考图已经证明的视觉机制做同类扩展，不得无依据地跨到无关素材类型。

## 变量提示词语法

要求下游模型生成的每条变量提示词由两部分组成：

1. 一段完整、连贯、可直接展开的中文生图提示词正文。
2. 正文后独立的 `可变项：` 定义块。

变量统一使用双大括号。定义格式为：

```text
{{语义变量名}}：选项一 / 选项二 / 选项三
```

强制执行以下规则：

- 每个变量同时出现在正文与 `可变项：` 定义块中，名称逐字一致。
- 不得有仅定义未使用或正文使用却未定义的变量。
- 使用表达视觉作用的名称，如 `{{核心符号}}`、`{{承载结构}}`、`{{包围方式}}`、`{{主体材质}}`、`{{空间层级}}`、`{{外围环境}}`。
- 禁止使用“变量一”“变量组A”“元素二”等无语义名称。
- 每套模板只变量化真正需要裂变的内容，不要把整段话全部变量化。
- 用户未规定数量时，每个图标变量原则上提供不少于 6 个有实质差异的选项；证据不足时不得用近义词凑数。
- 不同变量的选项必须能自由组合，不依赖隐藏条件、分支或另一个变量的特定取值。
- 任意组合展开后都应语法连贯、结构合理、可以直接生图。
- 固定比例、构图硬约束、质量要求和排除项不得变量化。

## 具体提示词兼容性

要求 SOP 保证变量展开后的具体提示词：

- 不再包含双大括号或未解释的占位符
- 不依赖参考图、上一条结果或外部上下文
- 不使用“同上”“保持一致”等省略表达
- 完整描述主体、结构、构图、材质、色彩、背景和光影
- 能直接提交给图片生成模型

## 固定排除项

要求 SOP 将下句完整加入每套变量提示词正文，不得变量化或删减：

```text
不得从参考图复制或重新生成任何文字、数字、字母、标题、正文、价格、保险条款、投保条件、免责声明、Logo、品牌标识、水印、二维码、角标、按钮、仿按钮控件、箭头或方向指示图形；不得生成任何国家或地区的国旗、国徽、天安门及其相关建筑变体、剪影或装饰元素。
```

## 输出格式

最终只输出：

```text
SOP名称：
不超过 6 个汉字，具体描述视觉结构。

SOP说明：
一至两句话说明适用素材、固定视觉骨架和结构裂变能力。

SOP正文：
完整、可独立执行的变量提示词生成 SOP。
```

不要输出参考图分析、观察证据、普通提示词、变量提示词实例、使用教程或自检记录。

## 输出前检查

- SOP 名称不超过 6 个汉字且具体。
- SOP 已脱离参考图独立执行。
- SOP 明确要求精确生成用户指定数量的变量提示词模板。
- 结构裂变优先于换色、换材质和换主体。
- 每条下游结果必须包含正文和独立的 `可变项：` 定义块。
- 变量正文与定义块可被瀚海规则识别，名称逐字匹配。
- 变量选项可自由组合并能完整展开。
- 固定排除句已完整写入。
